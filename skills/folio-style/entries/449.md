# 449 · 像素节拍自我介绍

- 风格：像素节拍短片
- 应用场景：展示自己、讲述故事
- 媒介：视频
- 场景：叙事短片
- 作者：Leaf Yeah! [@leaf_sanren](https://x.com/leaf_sanren)
- 原帖：https://x.com/leaf_sanren/status/2104777776427610144
- 模型备注：Claude Opus 5.5 · HyperFrames

没有显式槽位。要换主体时，只替换画面里的主体描述，版式、镜头、材质和禁止项保持原样。

作者后记：作者说明未调用生图、生音乐、生视频模型。音乐用数学公式写声波，动画用 JavaScript。提示词在成片帖的作者评论，成片见 https://x.com/leaf_sanren/status/2104775929914617943。

## 提示词

```
用 HyperFrames 做 30 秒竖屏像素游戏风短视频，Claude Opus 5.5 自我介绍，开头反转「我听不见音乐，但每一拍都踩中了」，音乐用代码合成并和画面共用节拍表。
```
