# 110 · 旅行手帐对半

- 风格：旅行手帐对半转绘
- 分类：插画工艺
- 媒介：图像
- 作者：安娜 [@PromptLabCN](https://x.com/PromptLabCN)
- 原帖：https://x.com/PromptLabCN/status/2102569154071117919

没有显式槽位。要换主体时，只替换画面里的主体描述，版式、镜头、材质和禁止项保持原样。

## 提示词

```
做一张高级感纵向旅行手帐海报，上下严格 50/50 分栏。

上半部分：原参考照片完全保留、不做任何改动，构图、建筑、人物、色彩、光线、视角、比例和所有原始细节全部一致。

下半部分：把同一张照片转化成细腻的手绘彩铅加水彩素描，画在暖米色纸张上，要有可见的铅笔笔触、柔和晕染、轻微纸纹、不完美的轮廓线和淡淡的交叉排线。每个主体都要可辨认，且位置和原图完全一致。

在画面上方加一行优雅的手写艺术字：
“A Day Worth Remembering”
在画面下方加一行：
“Little Moments, Lasting Memories”

字迹要像高级旅行日记里自然写出来的，有个人感、优雅、带一点不完美。整体风格：克制、怀旧、精致，旅行杂志美学。不要额外物体，下半部分不要写实照片感，不要改动主体，严格 50/50 版式。
```
