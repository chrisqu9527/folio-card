## 提示词

```
2x2 grid, 16:9, do this for 4 topics that were in the news:  
INPUT = [SUBJECT]

V = {
  CONFLICT   : auto | authority vs resistance | expectation vs reality | desire vs restraint,
  ROLES      : subject-derived opposing forces,
  CHARACTER  : human | creature | object | machine | metaphor | abstract,
  HUMOR      : deadpan | dry | defiant | sarcastic | innocent | absurd,
  DEMAND     : 1–4 words,
  RESPONSE   : 1–5 words,
  GESTURES   : subject-specific opposing body language,
  TOPOLOGY   : confrontation | power imbalance | inner conflict | object rebellion,
  PALETTE    : off-white + near-black + one subject-derived accent,
  FORMAT     : square | portrait | landscape
}

C₁  SEMANTIC CONFLICT ENGINE (master)
    infer SUBJECT identity, habits, frustrations, pressures, contradictions and recognizable symbols; discover ONE universally understandable tension: FORCE A demands/ expects something, FORCE B resists or contradicts it. Prioritize relatable absurdity.
    ¬C₁ = generic disagreement / forced conflict / unrelated humor / weak subject specificity.

C₂  ADAPTIVE OPPOSING CHARACTERS
    personify [ROLES] using subject-appropriate [CHARACTER] forms: authority → commanding entity; resistance → stubborn creature/object/idea; abstract conflicts → opposing visual metaphors. Preserve recognizable identities with minimal anatomy.
    ¬C₂ = default cats / arbitrary mascots / visually indistinguishable roles / unnecessary characters.

C₃  MICRO-DIALOGUE COMEDY
    generate [DEMAND] and [RESPONSE] as a two-beat joke: terse instruction → unexpected deadpan refusal, literal interpretation or ironic contradiction. Adapt [HUMOR] to SUBJECT; every word must sharpen the conflict.
    ¬C₃ = long dialogue / explanatory punchlines / recycled jokes / weak contrast.

C₄  GESTURAL CONFRONTATION
    stage ONE clear interaction through contrasting [GESTURES]: urgency vs indifference, command vs refusal, pressure vs relaxation, confidence vs stubbornness. Amplify posture and scale before facial detail.
    ¬C₄ = static characters / redundant gestures / confusing relationships / theatrical clutter.

C₅  MINIMAL EXPRESSIVE ANATOMY
    use oversized emotional eyes when appropriate, simple brows, tiny mouth marks and strong readable silhouettes. Anthropomorphize objects or abstract ideas only as much as needed for immediate emotional recognition.
    ¬C₅ = elaborate anatomy / excessive expression lines / realism / overdesigned mascots.

C₆  CONFLICT-DRIVEN TOPOLOGY
    select [TOPOLOGY]: direct argument → left/right confrontation; power imbalance → large vs tiny; internal conflict → divided figure/inner voices; object rebellion → agent facing resistant object. Preserve spacious framing and one compact speech bubble.
    ¬C₆ = fixed two-character layout / multiple competing scenes / awkward dialogue placement.

C₇  NAIVE EDITORIAL CARTOON LANGUAGE
    thick wobbly near-black marker contours, imperfect rounded shapes, sparse flat color, faint paper grain, off-white background and ONE restrained [PALETTE] accent. Casual lowercase hand-lettering with generous spacing; almost zero shading.
    ¬C₇ = polished corporate vectors / gradients / detailed scenery / multicolor rendering.

C₈  DEADPAN VISUAL ECONOMY
    compose for [FORMAT] with two clear opposing forces, short dialogue, expressive negative space and minimal subject-specific props. The visual contradiction should remain understandable even with speech text hidden.
    ¬C₈ = background clutter / unnecessary objects / tiny dialogue / weak character contrast.

η   COMEDIC CONFLICT COHERENCE
    one subject-specific tension, two instantly readable opposing forces, one terse demand–reply exchange, economical gestures, charming imperfect ink, restrained accent, abundant whitespace, minimalist webcomic clarity.

FORBIDDEN = generic cat defaults · forced arguments · lengthy dialogue · explanatory jokes · stock mascots · decorative props · elaborate backgrounds · excessive facial detail · glossy vectors · photorealism · weak punchline
```
