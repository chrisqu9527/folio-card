## 提示词

```
创建一张专业游戏/动画角色 Character Sheet。原创成年女性高空遗迹勘探员：暖棕肤色、短而凌乱的银灰发、透明青绿色护目镜、旧橙色技术夹克、深灰工装裤、米白重型靴、青绿色圆柱形呼吸背包。

Character Lock：所有视图必须保持完全相同的脸部结构、发型、身体比例、服装裁片、背包结构、颜色和磨损位置，不重新设计角色。

从左至右严格排列：全身正面 → 90°侧面 → 全身背面 → 3/4动作视图；右侧独立展示护目镜和呼吸背包的装备拆解。所有人物保持相同尺度，脚底位于同一水平线，彼此不遮挡。

米白色角色设计纸背景，精确墨线 + 克制的概念设计厚涂，能够看清布料接缝、扣具、金属磨损和装备连接方式；均匀柔光，不使用戏剧化景深。无文字、无Logo、无水印，不增加额外人物或重复装备。
```
