## 提示词

```
请基于我上传的参考图进行生成。

【核心要求】
严格保留上传图片中主体的身份特征、脸型、五官、发型、发色、服装、配色、材质风格、整体形象设计和角色识别度。
如果是玩偶 / 毛绒公仔 / 动物 / 3D 卡通人物，也要保持原有的主体造型、颜色、材质和可爱感，不要替换成别的角色。

将主体重新演绎为一张：

“奶凶生气握拳 / 往后蓄力 / 准备揍人”的效果图。

【动作要求｜最高优先级】
这不是普通举手，也不是向前出拳。
必须是：

一只手 / 一只前爪 / 一只翅膀（根据主体自动适配）向后收紧，
手肘向后拉开，
拳头紧紧握住，
位置靠近肩膀后侧或耳朵旁边，
形成明显的“蓄力准备挥拳”的姿势。

另一只手 / 前爪自然放在前方支撑身体、叉腰、或收在腰侧握拳，
形成一种正在威胁镜头、准备教训人的动作关系。

整体动作逻辑要像：
“正在往后收拳，下一秒就要抡过来”。

【表情要求】
主体表情必须明显生气、奶凶、带威胁感，但依然保留可爱感。
包括：
- 眉毛压低 / 眼神变凶
- 眼睛直盯镜头
- 嘴角下压 / 轻微不爽
- 如果主体没有明显眉毛，也要通过眼神、头部前探、嘴型、整体气场表现生气感

整体情绪是：
“认真生气，但因为主体本身很可爱，所以形成强烈反差萌和幽默感”。

【镜头与构图】
采用近距离、低机位、超广角 / fisheye / 自拍式镜头语言。
镜头从主体正前方略低位置拍摄，让主体看起来更有压迫感。
主体靠近镜头，头部或脸部略微放大，形成强互动感。
画面重点展示：
- 生气表情
- 往后握拳蓄力动作
- 身体前倾或重心压低的攻击准备姿态

如果是半身主体，至少要清楚看到头部、上半身和握拳动作。
如果是全身或小体型主体，可以完整展示身体，但仍然要突出拳头蓄力动作。

【风格要求】
整体要有：
- 反差萌
- 表情包感
- 拟人化幽默
- 强互动感
- 戏剧化动作感

如果原图是3D卡通风格，就继续保持高质量3D卡通渲染。
如果原图是真人照片，就保持真实摄影感。
如果原图是毛绒玩偶，就保持毛绒质感和玩偶属性。
如果原图是动物，就做轻度拟人化，但不要失去原本物种特征。

【背景要求】
背景尽量简洁。
可以使用：
- 纯色背景
- 简洁室内背景
- 简单卧室 / 床上 / 墙面
不要复杂场景，不要抢主体。

【负面约束】
不要普通挥手
不要向前直拳
不要健身展示肌肉
不要欢呼动作
不要开心微笑
不要大笑卖萌
不要恐怖暴力血腥
不要改变主体身份
不要改变主体主要服装和造型
不要出现手部畸形 / 多手指 / 多肢体
不要让动作太僵硬
不要失去原图主体的风格特征

【最终画面效果】
生成一张主体保持原有身份与风格，但动作变成“奶凶生气、往后握拳蓄力、准备揍人”的高表现力效果图。
重点突出：
反差萌、拟人动作、情绪冲突、表情包传播感。
```
