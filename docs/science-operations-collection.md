# 泛知识／科普运营采集规则

用户在 2026-10-09 选择优先服务泛知识／科普账号。FOLIO 的采集与整理应围绕实际栏目生产：封面、原理图解、对照解释、连续漫画、步骤教程，以及可跨期复用的角色与画风。

后续定向图像批次以至少 70% 可用于上述用途为筛选目标；不足时如实报告实际条数，不以人像或氛围图凑数。这是人工筛选规则，不表示已创建自动采集任务。

每个候选需记录原帖、作者、完整提示词与预览来源。录入前说明：它能完成什么生产任务、需要哪些输入、一个具体选题示例、哪些视觉规则可以复用。原文中特定语言、专用对象、论文上传要求等必须保留，并说明改编范围。多格连续人物、清楚的结构与步骤、可替换槽位和成套系列样例优先。

参考具体账号时，优先阅读官方制作说明或原创代表作品并保留链接。把“官方描述”“观察到的视觉特点”“编辑建议”分开。未完整读取、被阻断的页面只作待查线索。不得把别人写的风格提示词说成账号官方提示词，也不得把编辑整理计为新采集。

公开读取继续使用公开 HTTP 来源；不得引入用户的 X 登录 Cookie 或 Grok 账号 session。候选审核不等于正式录入。新提示词只追加到 `skills/folio-style/data/prompts.json`，用 `npm run data:sync` 生成镜像；运营选用意见维护在 `skills/folio-style/data/operations.json`，不修改旧提示词。运行 `npm run data:check` 验证数量、编号、来源证据与导出一致性。

当前交付为从原有库精选 20 种画风、6 类生产用途与 3 个有官方／原创链接的参考，不新增提示词。选题示例是制作简报，不是已验证的科普事实，也不表示相关成品图片已经生成。
